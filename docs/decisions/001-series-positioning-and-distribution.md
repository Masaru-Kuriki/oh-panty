# 判断001: シリーズ位置づけと配布範囲

決定日: 2026-06-05
ステータス: 確定

## 結論

- OH!PANTY! は **くりゲームス第2弾**、AN-NEN（白って200色あんねん）の**対作品**として制作する
- 配布範囲は **身内約10人クローズド**（AN-NEN同様）
- ホスティングは GitHub Pages or Cloudflare Pages、認証なし、URLを身内にだけ共有
- 検索除けに `robots.txt` で `Disallow: /` を設定

## 対作品関係（AN-NEN ↔ OH!PANTY!）

| 観点 | AN-NEN | OH!PANTY! |
|---|---|---|
| テーマ | 白の判別不能 | パンツ色の判別不能 |
| プレイヤーが見るもの | 白系100色のタイル | スカート姿の女の子 |
| 視覚ヒント | あり（薄い色差で判断） | **なし（完全カン）** |
| キメ台詞 | 「白って200色あんねん」 | **「OH! PANTY!」** |
| 1問難易度の上げ方 | 色差を細かく | 人数を増やす（Lv3最終問51人） |
| マスコット | アンミカ風キャラ | 保留（くりさん考案中） |

OH!PANTY! は AN-NEN よりさらに無理ゲー（完全カン）。プレイヤーは情報ゼロから1人を選ぶ。

## 技術スタック・サイト仕様の踏襲

AN-NEN の以下要素をそのまま踏襲：

- 素HTML/CSS/JS（フレームワーク不使用）
- サイト幅 480px、`100dvh`、セーフエリア対応
- Web Audio API 合成 + iOS自動再生制約対応コード
- GitHub Pages デプロイ
- プレイヤーカードUI設計（AN-NENで v1スコープ外としていたもの）

## コンテンツ的な配慮

- パンツがテーマだがクローズド配布のため過度な配慮不要
- ただし内輪でも温度感が分かれないよう **ポップで可愛い絵柄に統一**（線画＋フラットカラー）
- 下半身のみのベース絵で「めくる」演出にフォーカス、生々しさを回避
- マスコットキャラの方向性は別途決定

## ランキング機能の追加（AN-NENからの差分）

AN-NEN は v1 でランキングを実装せず、単発プレイのみだった。
OH!PANTY! ではくりさん要望により **Supabase でネット越しランキング**を v1 から実装する。

- 同一端末を10人で回す前提（プレイヤーカード方式）
- レベル別 Top10 × 3つ

これは AN-NEN の今後の拡張先（v2構想）を OH!PANTY! で先行実装する形。
