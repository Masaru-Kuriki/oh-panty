# マスコットキャラ案

保留中の項目。くりさん側で考案中とのこと。決まり次第このドキュメントを更新する。

## 必要な状態数

AN-NEN同様、リアクション画像として以下4種類が必要：

| 状態 | 使用シーン |
|---|---|
| 当たり | 正解時の演出 |
| ハズレ | ハズレ時の演出 |
| GameOver | ライフ0でゲームオーバー画面 |
| クリア | 全問正解でクリア画面 |

加えて、音声「OH! PANTY!」「早くしてよー」のキャラクター紐付け（同一キャラor別キャラ）が必要。

## 候補3案（参考）

### 案1: ピンク色のおじさん風マスコット（コミカル路線）
- 太ったハゲ頭、丸い体、ピンクの服 or 裸エプロン的なギャグ造形
- パンツテーマと結びつきが強い、AN-NEN「アンミカ」の強キャラ感に対応
- 「OH! PANTY!」と叫ぶキャラとして筋が通る
- 懸念: 内輪でも温度感分かれる可能性

### 案2: 制服風の進行役女の子（ポップ路線）
- ナース、メイド、女子高生など若い女性キャラ
- 表情豊か、可愛い系
- 「OH! PANTY!」「早くしてよー」を彼女が叫ぶ
- ベース絵柄（下半身のみ）とは別タッチになる点に注意
- 懸念: ベース絵の女の子と区別がつかなくなる可能性

### 案3: 擬人化マスコット（パンツマン的）
- パンツそのものがキャラクターになった存在
- ニュートラル、性別なし
- グッズ展開もしやすいポップさ
- AN-NEN「アンミカ風」級のインパクトは出にくい
